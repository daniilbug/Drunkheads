# Спрайты

PNG распределены по подсистемам: `bar/`, `cafe/`, `home/`, `street/` и другим.
Общие текстуры персонажей, включая базовое тело `player.png`, находятся в
`characters/`; текстура общей лампы — в `core/`.

`bar/source/` содержит исходные и прежние варианты графики бара. Это не текущие
игровые текстуры: `gen_bar_materials.py` использует часть этих PNG для сохранения
масок окон, дверных проёмов, силуэтов и деталей. Остальные прежние варианты
сохранены рядом; удалять их при очистке неиспользуемых игровых ресурсов не нужно.
Текущие текстуры бара находятся непосредственно в `bar/`.

При переносе PNG сохраняй его `.import` и UID, обновляй ссылки в сценах и
пути чтения и записи в генераторах `tools/`. Сцены должны ссылаться на исходный
PNG, а не на файлы кэша `.godot/imported/`.
