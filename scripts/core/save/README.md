# Сохранение мира

`SaveManager` — autoload: бинарные файлы в `user://saves`, проверка версии и данных,
временная запись с проверкой перед переименованием, три точки на прохождение.
Порядок точек задаёт сохранённая ревизия независимо от системных часов.

`WorldSave` под Main выбирает момент автосохранения и координирует восстановление.
Сцена интерфейса ошибок находится в `scenes/core/save/world_save.tscn`.
`Level` передаёт обход своего поддерева общему `SaveGraph`.

## Контракт объекта

Статический объект входит в группу `saveable` и реализует:

- `get_save_data() -> Dictionary` — только значимые поля;
- `apply_save_data(data: Dictionary) -> void` — восстановление этих полей.

Общие метаданные, координаты и владельца переносимого предмета сохраняет
`Draggable`. Его наследнику достаточно переопределить `get_save_schema()`:
массив задаёт допустимые значения, `Vector2i` — включительный целочисленный диапазон,
остальные значения — ожидаемый тип. Для особенностей предмета методы можно
расширить через `super`. Проверку связей выполняет `can_restore_save_data()`.

Новый динамический предмет регистрируется в существующем `MultiplayerSpawner`
уровня. Отдельного списка типов и полей в координаторе сохранений нет.

## Обход и загрузка

Каждый узел сохраняется один раз. Данные уровня содержат предметы с путями сцен
и родителей, а также состояния статических объектов по относительным NodePath.
Ссылки между объектами записываются путями или ID, сами Node и Resource в файл
не сериализуются. При загрузке сначала создаются недостающие предметы на всех
уровнях, затем применяются поля и восстанавливаются связи. Исчезнувшие предметы
удаляются из исходной сцены. Создание проходит через прежних владельцев спавна.

Записывает и восстанавливает мир только хост. Сохраняется персонаж хоста;
гости, NPC, транспорт и сессии мини-игр запускаются заново. Остаток свободных
фишек покера включается в сохранённый кошелёк без изменения текущей партии.
Во время поездки запись ждёт прибытия; остановившийся автобус сохраняется
даже до выхода пассажира, с безопасной позицией у остановки при загрузке.

Структура файлов версии 1 совместима с сохранениями до этого рефакторинга.
