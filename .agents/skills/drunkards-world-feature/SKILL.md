# Изменить функцию мира Drunkards

Обязательные правила: [архитектура](../../rules/architecture.md), [взаимодействия](../../rules/interactions.md). Для общего состояния прочитай [мультиплеер](../../rules/multiplayer.md), для статов и UI — [данные и сигналы](../../rules/data-and-signals.md), для визуальной части — [графику](../../rules/pixel-art.md).

1. Найди ближайший рабочий аналог в `scripts/` и его сцену в `scenes/`. Прочитай также базовую сцену и скрипт, чтобы сохранить унаследованные узлы, экспортируемые параметры и сигнальные соединения.
2. Определи владельца логики: объект, Room, Level или Main. Для нового объекта переиспользуй подходящий базовый тип; для комнаты продолжай Room, для уровня — Level и его границы/спавн. Размещай изменения в соответствующих парных каталогах.
3. Собери сцену с визуалом, нужной коллизией, Area, звуком и настройками. Проверь, что родитель зоны взаимодействия — ожидаемый объект; для двери учти взаимодействие со стеной комнаты, для мебели — Y-sort и места размещения.
4. Подключи действие через существующий путь Player: обычный `interact(player)`, специализированный вызов, Seat либо take/drop. Новую специальную ветку размещай с сохранением приоритета соседних действий. Переносимый предмет связывай через `take_spawned_item()` и `holder_peer_id`.
5. Для общего состояния выполни workflow [drunkards-multiplayer-feature](../drunkards-multiplayer-feature/SKILL.md). Изменения статов проводи через PlayerData, а события подключай в существующей инициализации владельца.
6. При добавлении в комнату или на улицу проверь размеры, доступность прохода, навигационную геометрию и преобразования координат. Сохрани работу Level как под Main, так и при самостоятельном запуске.
7. Выполни подходящие проверки из `AGENTS.md`: действие без предмета и с занятой рукой, перекрывающиеся зоны, занятое/свободное место или повторное открытие — по изменяемой механике. Для сетевой функции проверь host/client и поздний вход; для визуальной — используй workflow [drunkards-pixel-art](../drunkards-pixel-art/SKILL.md).

Образцы для выбора: `scripts/room/home/shower.gd` — специализация, `scripts/core/light_switch.gd` — переключатель, `scripts/street/cigarette_machine.gd` — выдача предмета, `scripts/room/bar/bar.gd` — инициализация содержимого комнаты.
