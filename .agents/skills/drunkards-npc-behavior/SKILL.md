# Изменить поведение NPC Drunkards

Обязательные правила: [архитектура](../../rules/architecture.md), [NPC](../../rules/npc.md), [мультиплеер](../../rules/multiplayer.md). При новых действиях с предметами прочитай [взаимодействия](../../rules/interactions.md).

1. Прочитай `scripts/core/npc.gd`, `NPCRoute`, затронутый сценарий в `scripts/levels/npc_routes/`, `Level.create_npc_route()`, настройки `NPCManager.configure()` в коде уровня, базовые действия Player и сцены целевых объектов. Определи вход в поведение, путь к цели, действие, завершение и выход при отсутствии цели.
2. Уровень выбирает отдельный объект маршрута для каждого NPC и задаёт параметры спавна; код сценария держи отдельно от уровня. Продолжи enum State и существующие переходы в `NPCRoute.update()`, вызываемом из `NPC._physics_process()`. Для ожиданий используй сброс `_elapsed_ms` setter состояния; параметры поведения размещай рядом с соответствующими константами.
3. Выбирай цель через существующие поиски свободных объектов и `_target_*` соответствующего маршрута. Учти резервирование во время подхода, проверку актуальности объекта и действие через его существующий API.
4. Прокладывай путь через `_set_destination()`. Проверь мировую дистанцию достижения с `_world_scale`, готовность navigation map и поведение при частичном маршруте. Смена состояния должна выбрать новую цель до анализа старого пути.
5. Для кабинок сохрани отдельные физические переходы входа/выхода; остальные перемещения продолжай через NavigationAgent и `velocity_computed`. При изменении геометрии проверь room/StreetNavigation и динамические препятствия.
6. Заверши поведение освобождением цели и занятого ресурса. Проверь `NPC._begin_exit()` и `NPCRoute.cleanup()`, уход с места, выключение используемого объекта и удаление NPC; сохрани восстановление популяции через NPCManager.
7. Проверь полный затронутый цикл на сервере и его отображение на клиенте. Дополнительно проверь относящиеся к задаче случаи: нет свободной цели, объект занят другим NPC, путь недостижим, несколько NPC идут рядом, уровень запущен отдельно. Для навигационных изменений проверь реальный масштаб Main и проходы у дверей.

Результат должен продолжать существующую машину состояний и повторно использовать предметные действия Player и объектов мира.
